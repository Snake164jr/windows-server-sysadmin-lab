\# Windows Server Systems Administration Lab



\## Overview



This project documents my hands-on systems administration lab built to develop and demonstrate practical Windows Server administration skills.



The environment will simulate a small enterprise network using multiple virtual machines, including Windows Server, Windows 11, and Linux systems.



\## Skills Demonstrated



This project will include hands-on experience with:



\- Windows Server administration

\- Active Directory Domain Services (AD DS)

\- DNS

\- Organizational Units (OUs)

\- User and group administration

\- Group Policy

\- Windows domain joins

\- NTFS and share permissions

\- File services

\- PowerShell administration and automation

\- Remote administration

\- Windows Event Viewer and troubleshooting

\- Backup and recovery

\- Linux administration and SSH

\- Virtualization

\- Network troubleshooting



\## Lab Environment



| System | Operating System | Purpose |

|---|---|---|

| DC01 | Windows Server | Domain Controller / AD DS / DNS |

| SRV01 | Windows Server | Member Server / File Services |

| CLIENT01 | Windows 11 | Domain-Joined Workstation |

| LINUX01 | Ubuntu Server | Linux Administration |
